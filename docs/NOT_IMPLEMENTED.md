# 미구현 기능과 알려진 한계

## 의도적으로 제외 (지시서 기준)
- 공개 채팅 — 종교 공간의 성격과 관리 부담을 고려해 이후 별도 결정
- 사제·수녀·고해성사 NPC
- 점수·랭킹·기도 횟수 보상
- FPS 기능(서버 권위, 명중 판정, 체력, 클라이언트 예측, 지연 보상, 안티치트) — 문서로만 정리
- 성경 독서 화면 — 코드는 남겨 두고 `src/lib/features.ts` 의 `bible: false` 로 꺼 둠 (다음 업데이트에서 다시 결정)
- 외부 성경 API 연동 — 구조(`BibleProvider` 인터페이스)만 준비

## 알려진 한계
- **Broadcast 발신자 위조**: Supabase Broadcast는 메시지마다 보낸 사람을 서버가 검증하지 않습니다.
  Presence에 있는 id의 메시지만 받지만, 같은 방 참가자가 다른 사람 id로 위치를 보내는 것은 막지 못합니다.
- **지연 측정값**은 '보낸 시각 → 받은 시각' 차이라 서로 다른 기기 간에는 시계 차이가 포함됩니다. 같은 컴퓨터의 두 브라우저에서 측정하면 정확합니다.
- 브라우저 탭이 백그라운드로 가면 렌더링(requestAnimationFrame)이 멈춰 위치 전송도 멈춥니다. 다른 사람에게는 마지막 위치에 서 있는 것으로 보입니다.
- 2D 기도 모드는 개인 기도용이라 실시간 방에 연결하지 않습니다.
