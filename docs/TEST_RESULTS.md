## Phase 3 수동 테스트 절차 (Supabase 설정 후 직접 실행)

준비: [SUPABASE_SETUP.md](SUPABASE_SETUP.md) 완료, 설정(⚙) → "네트워크 정보 표시" 켜기

1. **2명**: 일반 창 + 시크릿 창으로 접속 → 서로의 아바타와 `이름 #태그` 표시, 칩에 "함께 머무는 사람 2명"
2. 한쪽에서 걷기 → 다른 쪽에서 부드럽게 움직이는지 확인. 앉기/일어나기 → 상대 화면 반영
3. 한쪽 탭 닫기 → 상대 화면에서 몇 초 안에 사라지는지 확인
4. 개발자 도구 → Network → Offline 10초 → Online → "다시 연결하는 중…" 후 복구되는지 확인
5. **5명 / 10명**: 여러 기기·브라우저 프로필로 접속, 네트워크 정보의 `send Hz`(5명 3.2, 10명 1.0)와 `msg/s` 기록
6. **지연**: 같은 컴퓨터 두 창 사이 `latency*` 값 기록(다른 기기 간에는 시계 차이 포함)
7. **사용량**: 테스트 전후 Supabase 대시보드 Usage → Realtime messages 차이 기록
8. **모바일**: 실제 휴대폰에서 같은 Wi-Fi로 `http://<컴퓨터 IP>:3100` 접속, 조이스틱·묵주기도·2D 모드 확인

## 참고: 개발 중 알게 된 환경 이슈
- 외장 exFAT 드라이브는 심볼릭 링크를 지원하지 않음 → `npm install --no-bin-links` 사용
- macOS가 만드는 `._*` 파일이 `.next` 캐시에 섞이면 Turbopack 빌드 실패 → `prebuild` 스크립트로 자동 정리
- 브라우저 창이 숨겨져 있으면 렌더링이 초당 몇 프레임으로 제한됨(이동 속도·전송도 같이 느려짐) — 앱 문제가 아님
