### 실제 Supabase 테스트 중 발견해 고친 문제 (2026-10-29)
1. **연결 시도 경쟁(race)**: 개발 모드에서 React가 연결 effect를 두 번 실행(연결→해제→연결)하면서 이전 연결 시도가
   늦게 끝나 채널이 겹치는 문제 → 첫 입장 때 재연결 1회 발생. 연결 시도 번호(generation)로 오래된 시도를 중단하게 수정 → 이후 재연결 0회.
2. **이름표 사라짐**: drei `<Html>` 이 앉기/서기 전환 때 내부 React root를 렌더링 중에 해제하면서 오류가 나고 이름표가 사라짐 →
   캔버스 텍스처 스프라이트 이름표로 교체. 새 탭에서 콘솔 오류 0건 확인.
3. 같은 브라우저 탭 두 개는 로그인을 공유해 '같은 사람'이 되므로, 테스트용 `?profile=이름` 파라미터를 추가(탭마다 다른 익명 사용자).
